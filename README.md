# timer
simple timer with python
Entering the desired number, specifying seconds or minutes, makes it measure the time, and specifying the alarm sound determines whether the alarm sound will be played or not.
## availeble languages
english and persian
### Available versions
console and graphics
#### librarys used for both versions
playsound==1.2.2, time, wxpython, json, threading, os, sys
##### How to run
Put the .py file next to the sounds, and run it, install the libraries so that you don't get into trouble
